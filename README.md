# نظام إدارة وتسجيل التدريب 2027 — زهران ماركت

نظام متكامل لإدارة **تنفيذ** الخطة التدريبية 2027، مربوط مباشرة بـ
[نظام الاحتياجات التدريبية والخطة السنوية](https://zahranld.github.io/plan2027/).

```
احتياج (plan2027) ← برنامج (plan2027) ← جلسة منفذة + حضور (هذا النظام) ← تقييم أثر L1–L4 ← تقارير
```

## دليل الاستخدام
[دليل الاستخدام PDF خطوة بخطوة بالصور](docs/training-guide-2027.pdf) — متاح أيضًا على: `zahranld.github.io/record2027/docs/training-guide-2027.pdf`

## الوحدات

| الوحدة | الوظيفة |
|---|---|
| لوحة القيادة | مؤشرات المخطط مقابل الفعلي: الجلسات، المتدربون، الساعات، الحضور، الرضا، التعلم، التكلفة، تغطية الاحتياجات + التنبيهات |
| التنفيذ والحضور | كل جلسة مخططة في الخطة تظهر تلقائيًا؛ تسجيل التنفيذ الفعلي، المدرب، المكان، التكلفة، كشف الحضور (لصق/استيراد من Excel)، القبلي/البعدي، الرضا + التدريب غير المخطط |
| البرامج | المخطط مقابل الفعلي لكل برنامج ونسبة التنفيذ والاحتياجات المرتبطة |
| الموظفون | السجل التدريبي لكل موظف (ساعات، برامج، نتائج) مقارنة بالمستهدف السنوي + طباعة السجل |
| التقييم | نموذج كيركباتريك: L1 و L2 تلقائيًا، L3 متابعة التطبيق (بموعد استحقاق)، L4 الأثر على مؤشر الأداء من الخطة |
| الميزانية | التكلفة المخططة من الخطة مقابل الفعلية شهريًا وحسب البرنامج + تكلفة ساعة المتدرب |
| الاحتياجات | حالة تلبية كل احتياج مسجل في نظام الاحتياجات |
| تعديلات الخطة | نسخة الأساس مقابل الخطة الحالية مقابل الفعلي، تفاصيل كل برنامج مضاف/محذوف/معدّل، سجل تلقائي بتعديلات الخطة، وإعادة ربط التسجيلات |
| المدربون | سجل المدربين وأداؤهم |
| التقارير | تقرير أسبوعي/شهري/ربع سنوي/تراكمي جاهز للطباعة PDF + نص جاهز للبريد/واتساب |
| الإعدادات | الربط بالخطة، معايير التقييم، بيانات الموظفين، النسخ الاحتياطي، كلمة السر |

## الربط بنظام الاحتياجات
- يقرأ النظام البرامج والجلسات والاحتياجات **مباشرة (قراءة فقط)** من نفس قاعدة بيانات plan2027 عند كل فتح وكل 5 دقائق.
- إن تعذر الاتصال يعمل على آخر نسخة محفوظة، أو على النسخة المدمجة داخل الملف، أو على نسخة JSON مستوردة من plan2027.
- بيانات التنفيذ مربوطة بمعرّف البرنامج + رقم المجموعة؛ أي تعديل في مواعيد الخطة يظهر هنا دون فقد التسجيلات.

## الخطة تقديرية وقابلة للتعديل
- التعديل يتم في نظام الاحتياجات فقط (المصدر الوحيد للخطة)، ويظهر هنا تلقائيًا؛ كل المؤشرات تُحسب على **الخطة الحالية**.
- عند أول تشغيل تُحفظ "النسخة التقديرية الأولى" كنسخة أساس، ويمكن اعتماد نسخ أساس جديدة (مثل: الخطة المعتمدة بعد موافقة الإدارة) من صفحة تعديلات الخطة.
- كل تعديل يُرصد ويُسجَّل (التاريخ، البرنامج، البند، القيمة قبل وبعد) ويظهر في التقارير الدورية وفي ورقة Excel مستقلة.
- لا تُحذف أي بيانات تنفيذ عند حذف برنامج أو تقليل مجموعاته؛ تظهر كـ"تحتاج إعادة ربط" ويمكن نقلها لجلسة أخرى في الخطة الحالية.

## التخزين
بيانات التنفيذ محفوظة على المتصفح (localStorage) مع نسخ احتياطي/استعادة JSON وتصدير Excel كامل (7 أوراق).
للمزامنة بين أكثر من جهاز يمكن تفعيلها لاحقًا بنفس أسلوب plan2027.

## النشر

## التطوير
الملف النهائي `index.html` مبني من `src/` عبر:
```bash
node tools/build.js <مسار plan2027/index.html> src index.html
```
(يأخذ الخط المدمج ونسخة احتياطية من بيانات الخطة من ملف plan2027.)
